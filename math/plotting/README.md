# Math - Plotting

This project covers data visualization using Python, NumPy, and Matplotlib.

## Tasks

- `0-line.py`: Plot a line graph.
- `1-scatter.py`: Create a scatter plot.
- `2-change_scale.py`: Plot exponential decay using a logarithmic scale.
- `3-two.py`: Compare two radioactive decay curves.
- `4-frequency.py`: Display a histogram of student grades.
- `5-all_in_one.py`: Combine multiple plots in one figure.
- `6-bars.py`: Create a stacked bar chart.

## Requirements

- Python 3
- NumPy
- Matplotlib
