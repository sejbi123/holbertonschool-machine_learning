
# Pandas

## Description
This project introduces data manipulation and analysis using Pandas.

## Tasks
- Create DataFrames from NumPy arrays and dictionaries.
- Load data from CSV files.
- Manipulate and clean data.
- Analyze and visualize data.

## Requirements
- Python 3.9
- NumPy 1.25.2
- Pandas 2.2.2
- pycodestyle 2.11.1
