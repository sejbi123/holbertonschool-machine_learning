# Data Collection - APIs

## Description

This project focuses on collecting data from APIs using Python and the `requests` library.

## Task 0: Can I Join?

The `0-passengers.py` script retrieves starship data from the Star Wars API and returns the names of starships that can carry at least a specified number of passengers.

## Concepts

- HTTP GET requests with `requests`
- JSON response handling
- API pagination
- Parsing and validating passenger capacity valuesss
